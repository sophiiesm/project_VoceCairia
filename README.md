# Projeto Você Cairia? — Simulação educativa

Simulação acadêmica de phishing para a disciplina de Segurança da Informação.

## Fluxo
1. Feed visual inspirado no formato de uma publicação de plataforma de vídeos.
2. Oferta simulada de um programa de recompensas.
3. Cadastro fictício com nome e e-mail.
4. Encerramento da simulação e explicação educativa.
5. Perguntas de percepção para a atividade.

## Segurança
- Nenhum dado dos formulários é enviado a servidor.
- Nenhum dado pessoal é armazenado.
- Não existe autenticação real.
- A resposta da pesquisa é apenas exibida localmente na tela.
- O projeto deve ser utilizado somente no contexto autorizado da atividade escolar.

## Arquivos
- `index.html` — primeira etapa da simulação.
- `login.html` — cadastro fictício.
- `resultado.html` — revelação, explicação e pesquisa.
- `style.css` — identidade visual e responsividade.
